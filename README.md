# Next.js + Decap CMS POC

## Installation

```bash
npm install
```



## Running with local CMS

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.


## Accessing CMS admin page

Open [http://localhost:3000/admin](http://localhost:3000/admin) to access the CMS admin page.

## Building static site

```bash
npm run build
```

## Running static server locally

```bash
npm run start
```
